## Selected engineering work

### [SolTip — payment links & agent tool metering](https://github.com/Blessed-Shammah/solona_tips)

**TypeScript · Next.js · Solana · SQLite · MCP**

A payment-link application with server-side transfer verification, reconciliation and a ledger, extended with metered tools for AI agents. The code covers invoice references, replay handling, prepaid credits, rate limits and an MCP interface.

**Engineering focus:** payment state transitions, idempotency, durable records and API design. Includes payment and metering tests, CI and Docker configuration.

### [UI/UX Agent — a toolkit for coding agents](https://github.com/Blessed-Shammah/UI-UX-Agent)

**JavaScript · Node.js · Python**

A local CLI and importable API that inspect a project's stack, rank compatible design resources, compose implementation briefs and install agent instructions. The planner considers platform, existing libraries, licensing constraints and motion preferences.

**Engineering focus:** reusable tooling, explicit validation, explainable decisions and portable integrations. Includes automated tests for the planner, CLI, installer and review workflows.

### [FileVault — file sharing across web & mobile](https://github.com/Blessed-Shammah/Xender-Like)

**Node.js · Express · Flutter · Dart · Vite**

A shared backend serving a web client and a Flutter app for local-network file sharing. Supports uploads, downloads, search, category filtering and storage statistics, with Docker configuration for the combined application.

**Engineering focus:** multipart uploads, file metadata, REST endpoints and client/server integration across devices.
